# 外贸营销与业务套件

0.1.0受控试用版：12岗位、14项独立编写工作技能。适合搜索/LinkedIn研究、内容与邮件草稿、授权受控触达及尽调、单证、寻源、图片和站点支持。支持关键词加国家/客户角色；不承诺找到全网所有厂家。

从DesireCore官方市场安装本团队；最低客户端10.0.203。安装后在正常界面审阅并核准团队规则/名册，确认共享工作目录绑定及成员技能可用。安装者配置自己的模型服务与账号，不携带作者模型、凭据或个人测试数据。成员收纳在负责人下，用户展示偏好优先。详见[岗位分工](shared/岗位分工.md)。

第一次任务让负责人读取shared/rules.md，在实际团队工作目录按需从shared/templates复制空campaign/records，并使用shared/schemas检查。已有资料先读不覆盖，workspace与trade-data不提交Git。没有初始化任务时不需要先创建全部业务记录。

优先在系统邮箱管理登录邮箱；用户可指定其它可信已连接方式。社媒/地图等业务网页使用本机外置浏览器；已登录直接复用并核身份，未登录或验证码交本人。LinkedIn、Facebook、TikTok、X、Google Maps/Ads、外贸通和企业海关数据需用户自己的账号、许可与权限，部分需单独购买；模型及工具也可能计费。缺依赖停止相关调用并交付范围受限草稿。业务内容可能发送给用户配置模型及所选渠道，不宣称离线或零外发。

## 已有证据与边界

打包前已有LinkedIn研究和受控社交动作、Facebook双账号邀请/私信/帖子/评论、系统邮件受控往返、线索去重和部分正常中断恢复的控制者辅助验证。模拟咨询仅为功能验证，真实商业效果未验证。Facebook企业关键词检索、TikTok/X、授权企业海关、真实广告、硬崩溃/并发和完整无人值守仍待验证。新包装的静态与安装结果见[发布验证](validation/发布验证.md)，不能继承原非商业脚本测试结果。

## 立即体验

给“外贸营销负责人”：“先只读研究：以咖啡进口商为目标，国家由我指定，最多4次查询找3家候选；给官网、LinkedIn、匹配理由及未知项，不发送。缺地址时说明可继续的部分。”

后续按[接入与模拟验证](validation/接入与模拟验证.md)逐项执行；真实外发需用户明确对象和范围。团队只分发规则与资源，不包含渠道接通、付费服务或销售保证。
